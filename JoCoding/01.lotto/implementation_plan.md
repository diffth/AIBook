# 프리미엄 로또 번호 추천기 - 구현 계획서 (Implementation Plan)

## 1. 개요
현재의 **프리미엄 로또 번호 추천기**는 무작위로 번호를 조합하고 최근 기록을 일시적으로 보여주는 단순한 기능을 제공하고 있습니다. 사용자의 흥미를 자극하고 더 실용적인 도구로 발전시키기 위해, 로컬 데이터를 활용한 번호 보관 기능과 고도화된 필터링 기능, 그리고 시뮬레이션 요소를 추가하여 프리미엄 급 웹 앱으로 개선하는 계획을 수립합니다.
또한, 사용 편의성을 극대화하기 위해 한 번 클릭으로 실제 로또 1장 분량인 **5게임(A~E)을 동시에 추첨**할 수 있도록 개선안을 포함하고, 눈의 피로를 덜어주는 **다크 모드/라이트 모드 테마 토글 기능** 및 모바일 기기(최소 320px 해상도)에서 화면이 깨지지 않고 완벽하게 최적화되는 **고급 모바일 반응형 디자인**을 설계 및 구현합니다.

## 2. 주요 개선 및 추가 기능 계획

### 2.1 번호 생성 알고리화 및 필터링 기능
- **고정수 / 제외수 지정**: 사용자가 반드시 포함하고 싶은 번호(최대 3개)와 제외하고 싶은 번호(최대 5개)를 선택할 수 있게 합니다.
- **홀짝 비율 필터**: 번호 조합 시 홀수와 짝수의 비율(예: 3:3, 2:4, 4:2 등)을 선택할 수 있는 간이 필터 옵션을 제공합니다.
- **총합 범위 체크**: 생성된 6개 번호의 합이 일반적인 당첨 확률 분포에 속하는 범위(예: 100 ~ 170) 내에 오도록 자동 검증하는 옵션을 추가합니다.

### 2.2 5게임 동시 추첨 기능 (핵심 변경 사항)
- **한 번에 5개 세트 생성**: 사용자가 버튼을 한 번 클릭하면 6개 번호 조합을 총 5세트 동시에 생성합니다.
- **행 단위 레이아웃**: 생성된 5개 세트를 로또 용지와 같이 A, B, C, D, E 라벨이 달린 개별 행(Row)으로 정렬해 보여줍니다.
- **폭포수형 애니메이션 딜레이**: 공이 위에서 아래로 순차적으로 튀어나오는 다이내믹 지연 효과를 부여합니다.

### 2.3 영구 히스토리 및 즐겨찾기 (Local Storage 연동)
- **자동 저장**: 추천된 번호가 브라우저를 닫아도 날아가지 않도록 `localStorage`에 자동 저장하고, 최대 15개 게임까지 히스토리를 유지합니다. (최근 3회 추천분)
- **즐겨찾기(보관함) 기능**: 마음에 드는 번호 조합 옆의 '별(★)' 아이콘을 누르면 별도의 보관함 탭에 영구 저장됩니다.

### 2.4 모의 당첨 확인 시뮬레이터 (Lotto Win Simulator)
- **가상 추첨**: 가상의 1등 당첨 번호를 즉석에서 생성하거나 직접 당첨 번호를 입력하여, 내가 생성한 번호들이 몇 등에 당첨되었는지(1등~5등 및 꽝) 즉시 대조해보고 당첨 통계를 확인할 수 있는 미니 게임 요소를 제공합니다.

### 2.5 다크 모드 / 라이트 모드 테마 전환
- **테마 전환 버튼**: 오른쪽 상단에 직관적인 이모지(☀️/🌙) 형태의 테마 토글 버튼을 추가합니다.
- **상태 영구 보관**: 브라우저의 `localStorage`를 활용하여 사용자가 선택한 테마를 기억하고, 새로고침을 하거나 웹페이지에 다시 접속해도 그 테마가 끊김 없이 유지되도록 설계합니다.

### 2.6 반응형 및 모바일 가변 해상도 완벽 대응 (신규 변경 사항)
- **기기별 해상도 최적화**: 480px 이하의 표준 모바일뿐 아니라 360px 이하의 초소형 모바일 기기(아이폰 SE 등)까지 레이아웃 깨짐을 완전히 해소합니다.
- **가변 요소 스케일링**: 한 줄에 6개의 로또 공이 줄바꿈 없이 깔끔하게 배치되도록 뷰포트에 맞게 공 크기(32px/28px) 및 여백을 최적화합니다.
- **헤더 겹침 방지**: 모바일 뷰에서 테마 전환 버튼이 헤더 타이틀 텍스트와 겹치는 현상을 해결하기 위해 컨테이너 내부 상단 공간과 컴팩트 버튼 크기 조정을 적용합니다.

### 2.7 비주얼 & UX 고도화
- **공 굴리기 애니메이션**: 번호 생성 시 로또 기계에서 공이 굴러 나오는 듯한 생동감 넘치는 3D 회전/롤링 애니메이션 효과를 구현합니다.
- **클립보드 및 SNS 공유**: 생성된 최적의 번호 조합을 친구들에게 바로 카카오톡이나 텍스트로 공유할 수 있도록 클립보드 복사 버튼을 제공합니다.

## 4. 검증 계획

### 수동 검증
1. **모바일 375px(표준) 반응형 검증**: 모바일 가로 너비 375px 뷰포트에서 버튼 및 로또 공 6개가 단일 행에 줄바꿈 없이 정렬되어 렌더링되는지 검증.
2. **모바일 320px(초소형) 반응형 검증**: 아이폰 SE 규격인 가로 너비 320px 뷰포트에서 레이아웃 뭉개짐이나 글자 잘림 없이 모든 UI가 정상 표기되는지 검증.
3. **5게임 동시 생성 테스트**: 번호 받기 버튼을 클릭했을 때 정확히 A~E 라벨과 함께 5줄의 로또 조합(각 6개 공)이 올바르게 나타나는지 확인.
4. **애니메이션 딜레이 테스트**: 위에서 아래로 공이 물 흐르듯 순차적으로 나타나는지 확인.
5. **테마 전환 및 저장 테스트**: 테마 전환 버튼을 클릭하여 다크 모드와 라이트 모드가 부드럽게 스위칭되는지 확인하고, 라이트 모드 상태에서 페이지를 새로고침(F5)해도 유지되는지 테스트.
6. **필터링 테스트**: 고정수(예: 7)와 제외수(예: 13)를 설정하고 생성했을 때, 항상 7이 포함되고 13이 배제되는지 20회 이상 연속 테스트.
7. **저장 기능 테스트**: 번호를 여러 번 생성하고 즐겨찾기에 등록한 후, 브라우저를 새로고침(F5)해도 목록이 온전히 유지되는지 확인.
8. **시뮬레이션 테스트**: 당첨 번호를 가상으로 생성하여 내가 가진 번호들과 비교했을 때, 일치하는 개수에 따라 등수(1~5등)가 정확하게 매칭되어 화면에 나타나는지 검증.
