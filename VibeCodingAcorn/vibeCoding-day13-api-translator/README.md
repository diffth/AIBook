# Gemini AirTranslate (Day 13)

실시간 AI 번역 및 감정 분석 웹 애플리케이션입니다. Google Gemini API를 활용하여 사용자가 입력한 텍스트를 대상 언어로 자연스럽게 번역하며, 원본 텍스트에 내포된 긍정/중립/부정 감정 비율을 분석하여 제공합니다.

## 주요 기능
- **실시간 다국어 번역**: 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어 지원
- **감정 분석 대시보드**: 원본 텍스트의 감정 뉘앙스를 심층 분석하고 CSS 애니메이션 게이지로 시각화
- **데모 모드 (Mock Mode)**: API 키 없이도 번역 기능 및 인터랙션 시연이 가능한 모의 환경 내장
- **번역 기록 및 통계 트렌드**: 과거 번역 내역을 저장하고 누적된 감정 트렌드를 요약하여 보여줌
- **음성 인식 및 TTS**: 마이크를 통한 음성 입력 지원(웨이브폼 시각화) 및 번역 결과 텍스트 음성 출력 지원

## 사용 기술
- HTML5, CSS3 (다크 글래스모피즘 UI)
- Vanilla JavaScript (ES6+)
- Google Gemini API (gemini-1.5-flash)
- Web Speech API
