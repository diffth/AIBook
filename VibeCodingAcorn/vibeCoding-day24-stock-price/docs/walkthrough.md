# LSTM 주식 가격 예측 및 AI 시장 리포트 대시보드 개발 완료 보고서

TensorFlow LSTM 모델을 활용하여 사용자가 원하는 개별 주식 종목의 30일 미래 가격을 시뮬레이션하고, 기술적 지표 및 AI 시장 보고서를 미려한 다크 모드 트레이딩 보드로 시각화하는 웹 애플리케이션 개발을 완료하였습니다! 🎉

---

## 🛠️ 작업 내용 및 완료 사항

### 1. 백엔드 (Flask)
- `yfinance` 기반으로 과거 주식 시계열 데이터를 다운로드하고, `pandas`를 이용해 이동평균선(MA20, MA50) 및 RSI 지표를 실시간으로 계산하는 전처리 모듈을 구현하였습니다.
- Keras/TensorFlow 기반의 LSTM 2-레이어 Sequential 인공신경망 아키텍처를 작성하였으며, 실시간 예측 시 60일의 데이터 윈도우로 30일 동안 순환적(Autoregressive) 예측을 수행하여 역정규화하는 모델 로직을 구현하였습니다.
- Gemini API (`gemini-1.5-flash`)를 활용하여 현재 시장 현황, LSTM 예측 결과, 기술적 지표들을 유기적으로 분석하고, 격식 있고 논리적인 한국어 "AI 시장 분석 리포트"를 작성하는 요약 라우터를 구축하였습니다.

### 2. 프론트엔드 (React / Vite)
- 주식 트레이딩 모니터 감성의 세련된 네온 및 글래스모피즘 기반 다크 UI 디자인 시스템(`index.css`)을 구축하였습니다.
- 티커 입력, 기간 설정, LSTM 에포크 조절 슬라이더 및 실시간 훈련 단계를 보여주는 로딩 인디케이터를 포함한 설정 패널을 구현하였습니다.
- `react-plotly.js`를 연동하여 과거 주가 추이와 30일간의 미래 예측 가격(점선)을 매끄럽게 연결해 표시하는 인터랙티브 차트 컴포넌트를 완성하였습니다. (MA20, MA50 온오프 오버레이 지원)
- 최근 종가, 30일 예측가, 예상 등락률, RSI 수준, LSTM 에러율(MAE)을 일목요연하게 표시하는 그리드 카드 및 AI 분석 리포트 마크다운 뷰어를 탑재하였습니다.

## 💡 실행 및 가동 방법

### 1. 백엔드 실행
백엔드 폴더 내부에서 가상환경을 활성화한 뒤 Flask 서버를 구동합니다.
```powershell
cd backend
venv\Scripts\python app.py
```

### 2. 프론트엔드 실행
프론트엔드 폴더 내부에서 Vite 개발 서버를 구동합니다.
```powershell
cd frontend
npm run dev
```

> [!TIP]
> - Gemini 분석 리포트를 정상적으로 생성하기 위해, 백엔드 구동 전 `backend/.env` 파일 내에 `GEMINI_API_KEY=발급받은키` 형식으로 API 키를 입력해 주세요. (미설정 시 관련 기능 우회 처리됨)
