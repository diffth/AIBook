# 심플 계산기 기술 명세서 (VibeCoding-day04-simple-calc)

본 문서는 `vibeCoding-day04-simple-calc` 폴더에 구현된 HTML, CSS, JS 기반의 심플 계산기에 대한 기술 명세서입니다.

## 🎯 목표 (Goal Description)

사용자가 마우스 클릭 및 키보드 입력을 통해 직관적으로 수식을 입력하고 결과를 확인할 수 있는 세련된 디자인의 심플 계산기를 구현합니다.

### 📋 핵심 요구사항
1. **마우스 클릭 및 화면 표시**: 숫자 및 연산자 버튼 클릭 시 입력된 수식을 화면(Display)에 표시.
2. **Readonly 입력창**: 사용자가 직접 타이핑하여 텍스트를 수정하지 못하도록 입력창은 `readonly` 속성 적용.
3. **키보드 이벤트 지원**: 숫자, 기본 사칙연산(`+`, `-`, `*`, `/`), 그리고 `Enter` 키(또는 `=` 역할) 입력 처리.
4. **결과 연산**: 자바스크립트의 `eval()` 함수를 사용하여 문자열로 된 수식을 계산.
5. **계산 기록 관리**: 배열을 생성하여 최근 5개의 수식 및 결과(예: `"2 + 3 = 5"`)를 저장하고, 매 계산마다 콘솔(`console.log`)에 배열 상태를 출력.

---

## 🎨 디자인 및 UI 컨셉 (Design & UI Concept)

* **색상 테마**: 블루 계열의 밝은 톤(Light Blue Theme)을 메인으로 적용.
* **프리미엄 네오모피즘(Neumorphism) 및 글래스모피즘(Glassmorphism) 스타일**: 입체적이면서도 맑고 투명한 유리 질감의 계산기 레이아웃을 제공합니다.
* **반응형 디자인**: 모바일 화면에서도 꽉 차고 예쁘게 보이도록 비율을 조절합니다.

---

## 🛠️ 구현 구조

### 1. `index.html` (마크업)
* **레이아웃**: 계산기 컨테이너 내부에 디스플레이(출력창) 영역과 키패드(버튼) 영역을 분리.
* **출력창**: `<input type="text" id="display" class="display-input" readonly placeholder="0">` 요소를 배치.
* **키패드**: CSS Grid를 활용하여 숫자 버튼(0-9), 연산자 버튼(+, -, *, /), 초기화 버튼(AC/DEL), 결과 버튼(=) 등을 격자 형태로 배치.

### 2. `style.css` (스타일링)
* CSS Grid(`display: grid`)를 활용한 정밀한 버튼 배치.
* 버튼에 호버(Hover) 및 클릭(Active) 시 미세한 크기 변화(`transform: scale()`)와 그림자 트랜지션을 주어 누르는 맛(타격감)을 극대화.
* 맑고 상쾌한 블루 계열의 색상 팔레트 사용 및 모던한 느낌의 Inter 웹 폰트 적용.

### 3. `script.js` (기능 로직)
* **DOM 요소 참조**: 출력창(`input`)과 각 버튼들을 자바스크립트로 연결.
* **이벤트 리스너 등록**:
  * 각 버튼에 `click` 이벤트를 등록하여 클릭한 값을 출력창 문자열에 누적.
  * `window` 객체에 `keydown` 이벤트를 등록하여 허용된 키(숫자, 연산자, Enter, Backspace, Escape) 처리.
* **`eval()` 에러 처리**: `try...catch` 블록을 사용하여 잘못된 수식(예: `5++5`) 입력 시 에러가 나지 않고 "Error" 텍스트를 빨갛게 표시.
* **기록 관리 (History)**:
  * `const history = []` 배열 선언.
  * 계산 성공 시 `history.unshift(수식 + " = " + 결과)`로 맨 앞에 추가.
  * `if (history.length > 5) history.pop()`을 통해 최근 5개 유지.
  * 매 계산 완료 시 `console.table(history)`로 브라우저 개발자 도구 콘솔에 출력.
