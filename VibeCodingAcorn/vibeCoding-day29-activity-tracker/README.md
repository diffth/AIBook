# 🌟 Vivid Habit Tracker (비비드 습관 추적기)

HTML, CSS, JavaScript만을 사용하여 제작한 직관적이고 수려한 프리미엄 습관 추적기(Habit Tracker) 웹 애플리케이션입니다.  
별도의 서버 없이 브라우저의 로컬 스토리지(`localStorage`)만을 활용하여 즉시 실행 및 관리가 가능한 완전한 정적 구조입니다.

---

## 🎨 주요 특징

- **프리미엄 다크 테마 & 글래스모피즘**: 눈이 편안한 다크 모드와 몽환적인 3색 백그라운드 오라(Glow), 블러 처리된 카드 디자인이 조합되어 시각적 만족감을 극대화합니다.
- **7x5 데일리 진척도 그리드**: 주 단위로 구분된 총 35일(5주) 분량의 그리드를 토글식(Done / Undone)으로 기록할 수 있으며, 클릭 시 팝(Pop) 애니메이션과 함께 습관의 네온 컬러가 그리드에 밝혀집니다.
- **실시간 통계 수치**: 
  - **Current Streak (현재 연속 달성일)**: 마지막 체크일 기준 끊기지 않고 연속된 완료일 수를 실시간으로 역산하여 보여줍니다.
  - **Total Progress (전체 진행률)**: 35일 중 완료된 날의 비율을 계산하여 네온 프로그레스 바와 함께 수치로 표시합니다.
- **백업 및 가져오기 (JSON)**: 
  - `Export` 기능을 통해 현재 습관 정보와 기록 상태를 JSON 파일로 백업할 수 있습니다. (Chrome 86+ 브라우저에서는 `window.showSaveFilePicker()`를 통해 사용자 저장 창을 제공하며, 미지원 브라우저의 경우 호환 링크 다운로드 방식을 지연 처리하여 안정성을 확보했습니다.)
  - `Import` 기능을 통해 데이터의 깨짐 유무 및 35일 완성 일정을 정밀 검증 후 기존 환경으로 정상 복구할 수 있습니다.
- **전체 데이터 초기화 (Reset)**: 한 번의 클릭으로 로컬 저장소와 화면 데이터를 깨끗이 초기화합니다.

## 📁 파일 구조

```text
vibeCoding-day29-activity-tracker/
│
├── index.html   # 기본 마크업, 모달 뼈대, Lucide 아이콘 및 Google Font CDN 로드
├── style.css    # 글래스모피즘 스타일, 네온 컬러 정의, 애니메이션 및 모바일 미디어 쿼리

└── README.md    # 프로젝트 설명서 (현재 파일)
```

## 🚀 사용법 및 가이드

1. **실행 방법**:
   - `index.html` 파일을 더블클릭하여 일반 웹 브라우저에서 즉시 오픈하거나, 간단한 로컬 웹 서버(예: `live-server`, Python/Node http server)를 통해 실행할 수 있습니다.
2. **새로운 습관 만들기**:
   - 우측 상단의 `습관 추가` 버튼을 클릭합니다.
   - 습관의 이름, 상세 내용, 대표 이모지(아이콘), 그리고 네온 테마 색상을 선택하고 `생성하기`를 클릭하면 카드가 추가됩니다.
3. **그리드 토글**:
   - 카드 하단의 7x5(35일) 그리드 셀 중 달성한 일차의 번호를 클릭하면 네온 조명이 켜지며 Done 상태로 변경됩니다. 다시 클릭 시 취소(Undone)됩니다.
4. **데이터 백업 및 복원**:
   - 브라우저를 변경하거나 데이터를 보관하고 싶을 때 `Export` 버튼을 누르면 JSON 파일로 즉시 저장됩니다.
   - 백업한 JSON 파일을 가져오려면 `Import` 버튼을 눌러 파일을 선택하면 덮어쓰기 형태로 데이터가 복원됩니다.
