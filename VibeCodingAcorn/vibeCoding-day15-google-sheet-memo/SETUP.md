# 📋 Sheet Memo 설정 가이드

구글 시트를 데이터베이스로 활용하는 메모장 웹앱을 실제로 연동하기 위한 설정 가이드입니다.

> 💡 **설정 없이도 사용 가능합니다!**  
> `GAS_URL`을 설정하지 않아도 **데모 모드**로 UI와 대시보드를 미리 체험할 수 있습니다.

---

## 1단계: Google Sheets 생성

1. [Google Sheets](https://sheets.google.com)에 접속합니다.
2. **새 스프레드시트**를 생성합니다.
3. 스프레드시트 이름을 `Sheet Memo DB` 등 원하는 이름으로 변경합니다.

> ⚠️ **시트 이름은 자동 생성됩니다!**  
> `memo` 시트가 없으면 Apps Script가 처음 실행될 때 자동으로 생성합니다.  
> 수동으로 만들 필요 없습니다.

---

## 2단계: Google Apps Script 프로젝트 생성

1. 위에서 만든 스프레드시트에서 **확장 프로그램** → **Apps Script**를 클릭합니다.
2. Apps Script 에디터가 열리면 기존의 `myFunction()` 코드를 모두 삭제합니다.
3. 이 프로젝트의 **`Code.gs`** 파일 내용을 복사하여 붙여넣습니다.
4. 파일 이름을 `Code.gs`로 변경합니다 (기본값이 `코드.gs`일 수 있습니다).

---

## 3단계: 테스트 실행

1. Apps Script 에디터 상단에서 함수 선택 드롭다운을 **`testSetup`**으로 변경합니다.
2. **▶ 실행** 버튼을 클릭합니다.
3. 처음 실행 시 **권한 승인**이 필요합니다:
   - "승인 필요" 팝업에서 **권한 검토** 클릭
   - Google 계정 선택
   - "고급" → "Sheet Memo(안전하지 않음)(으)로 이동" 클릭
   - **허용** 클릭
4. 실행 로그에 `✅ memo 시트가 준비되었습니다!` 메시지가 나타나면 성공!
5. 스프레드시트로 돌아가면 `memo` 시트와 테스트 메모가 생성되어 있습니다.

---

## 4단계: 웹앱 배포

1. Apps Script 에디터에서 **배포** → **새 배포**를 클릭합니다.
2. 왼쪽 **유형 선택** 기어 아이콘 → **웹 앱**을 선택합니다.
3. 설정값:
   - **설명**: `Sheet Memo API`
   - **실행 권한**: `나`(내 계정)
   - **액세스 권한**: `모든 사용자` (반드시!)
4. **배포** 버튼을 클릭합니다.
5. **웹 앱 URL**이 표시됩니다. 이 URL을 복사합니다.

```
예시 URL:
https://script.google.com/macros/s/AKfycbx.../exec
```

---

## 5단계: 프론트엔드 연결

1. `script.js` 파일을 엽니다.
2. 파일 상단의 `GAS_URL` 상수를 찾습니다:

```javascript
// ★★★ 아래 URL을 Google Apps Script 배포 URL로 변경하세요 ★★★
const GAS_URL = '';
```

3. 복사한 웹앱 URL을 붙여넣습니다:

```javascript
const GAS_URL = 'https://script.google.com/macros/s/AKfycbx.../exec';
```

4. 저장 후 웹앱을 새로고침합니다.

---

## 🎉 완료!

이제 웹앱에서 작성한 메모가 구글 시트에 실시간으로 저장됩니다!

### 시트 구조 (자동 생성)

| A (id) | B (날짜) | C (제목) | D (카테고리) | E (내용) |
|--------|----------|----------|-------------|----------|
| 타임스탬프 | ISO 날짜 | 메모 제목 | 카테고리명 | 메모 본문 |

## 🔧 트러블슈팅

### "CORS 오류" 발생 시
- 배포 시 **액세스 권한**이 `모든 사용자`인지 확인하세요.
- `fetch`에서 `mode: 'no-cors'`를 추가하면 안 됩니다 (응답을 읽을 수 없게 됩니다).

### "권한 거부" 오류
- Apps Script에서 `testSetup` 함수를 실행하여 권한을 먼저 승인하세요.

### 코드 수정 후 반영 안 됨
- Apps Script 코드를 수정한 경우 **반드시 새 배포**를 해야 합니다.
- **배포** → **배포 관리** → **새 버전 만들기**를 클릭하세요.
