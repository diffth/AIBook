### 02. 실시간 1:1 채팅 서비스 (0401_chatsample)
- HTML, CSS, JavaScript (Vanilla Web SDK)와 Firebase Realtime Database를 연동한 1대1 라이브 메신저 서비스입니다.
- 인원이 0명이 되면 채팅방 노드를 자동 폭파하는 스마트한 청소 기능과 웹상에서 Firebase 설정을 직접 교체할 수 있는 환경설정 기능을 제공합니다.

### 03. 실시간 멀티플레이어 포커 게임 (0402_mypocker)
- Firebase Realtime Database와 매칭 상태 트랜잭션 처리를 활용해 다수의 플레이어가 동시 참여 가능한 실시간 텍사스 홀덤 포커 게임입니다.

### 04. 관심 주제 실시간 뉴스 크롤러 & 대시보드 (0403_mynews)
- 구글 뉴스 RSS와 Firebase를 연동하여 사용자가 등록한 관심 분야의 뉴스를 매일 실시간 수집 및 분류하고, 프리미엄 다크 모드 글래스모피즘 UI에서 보관 및 북마크할 수 있는 뉴스 허브 서비스입니다.
